# Lindow
Lindow is an education operating system, just for breaking and learning stuff. Currently I have implemented some of the cool stuffs. The rundown are below:

- [x] Bootsector code understanding the first sector MBR.
- [x] Input Interrupt via BIOS Interrupt vector and asm.
- [x] Loading Second Sector, switching RealMode to Protected Mode(32bits).
- [x] Run C binding as Kernel.
- [x] Run Rust binding as Kernel. 
- [x] Driver Support for VGA in rust
